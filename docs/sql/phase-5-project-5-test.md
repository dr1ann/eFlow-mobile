There must be exactly one matching active profile per email and one project named **Project 5**. The Head must already be authorized to create work in that project's organization. The project must have an organization, be planning/active, and have either no target date or a target date at least eight days after the seed date. The script stops with a useful error if these conditions fail; it does not change existing project settings or user permissions.

Dates are relative to the day the script runs in **Asia/Singapore**. Use that device time zone for the initial checks. A rerun preserves the fixture, including its original deadlines, review decisions, and uploaded evidence. A partial existing fixture is reported rather than overwritten. All creation runs in one transaction; an error rolls back that run. If your editor leaves an aborted transaction open, run `ROLLBACK;` before trying again.
